# Florence Clinic

Website for **Florence Nightingale Nursing**, a home-nursing care provider in Raj Nagar Extension, Ghaziabad, Uttar Pradesh.

> **Freelance client project.** Designed and built by [Amar Chaurasiya](https://github.com/Amar1244) for the clinic.

**🔗 Live site: [florencenursing.vercel.app](https://florencenursing.vercel.app)**

## Overview

The site lets patients and families find the clinic's home-care services, see lab packages and doctors, and contact the team or book through WhatsApp and phone.

## Features

- **Services:** injections and IV drip, wound dressing and suture care, tracheostomy care, physiotherapy, catheterization and other nursing procedures, medical equipment supply, and home sample collection for pathology tests
- **Lab packages:** health check packages with home sample collection
- **Online consultation** with a general physician by video or phone call
- **Doctors page** introducing the clinic's team
- **Reviews page** where patients can read and submit feedback
- **Quick contact:** WhatsApp buttons with pre-filled messages, click-to-call links and an emergency call button
- **SEO:** meta tags, Open Graph and Twitter cards, `sitemap.xml` and `robots.txt`
- Responsive layout for mobile and desktop
